# Kanban Board UI

A responsive Kanban board built with HTML, CSS, and JavaScript. It works directly in the browser and saves tasks using `localStorage`.

## Features

- Four task columns: To Do, In Progress, Review, and Done
- Add, edit, and delete tasks
- Drag and drop cards between columns
- Search tasks by title, description, owner, or priority
- Priority, owner, and due date fields
- Dashboard summary cards
- Responsive layout for desktop, tablet, and mobile
- Data persists in the browser with `localStorage`

## Files

- `index.html` - Main page structure
- `style.css` - Layout and UI styling
- `script.js` - Board interactions and saved task data

## How To Run

Open `index.html` in any modern browser.

No installation or build command is required.

## Usage

1. Click `+ Task` to create a new task.
2. Fill in the task details and save.
3. Drag cards between columns to update their status.
4. Use the search box to filter tasks.
5. Click `E` to edit a task or `D` to delete it.

## Tech Stack

- HTML5
- CSS3
- JavaScript
